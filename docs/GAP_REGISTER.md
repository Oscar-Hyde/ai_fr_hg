Status meanings:

- `OPEN` — owning phase has not completed the finding.
- `IN PROGRESS` — implementation/evidence is being produced in the current phase.
- `BLOCKED` — required work depends on an explicitly named external condition.
- `CLOSED — REMOVED` — unsupported behavior and its promise were comprehensively removed/hidden, with compatibility handling and regression evidence.
- `CLOSED — SCOPED` — product behavior was explicitly narrowed to what is implemented, with UI/docs/tests aligned.
- `CLOSED — IMPLEMENTED` — the complete acceptance contract passed.
- `REOPENED` — a row previously marked closed whose acceptance contract was **not** in fact satisfied. Re-audit evidence is recorded on the row. A reopened row may only close again on new evidence, never on the original claim.

A closed row is not permission to weaken the audit's cross-cutting requirements. Phase 7 still validates integrated behavior.

**The register is self-checking.** `TestRegisterEvidenceIsReal` fails the build if a CLOSED row cites a code symbol that no test references. Two rows (SEC-07, PIPE-04) were closed on evidence naming functions that had never been tested; that class of claim can no longer be written.

**Verification tiers.** Evidence is not interchangeable; every row states which tier it rests on.

| Tier | Proves | Cannot prove |
| --- | --- | --- |
| **Static / AST** | Structural invariants: wiring, reachability, one-route-per-operation. | That the code does the right thing when it runs. |
| **Framework validation** | Conformance to real Frappe v17 rules, cross-checked against a `frappe/develop` checkout. | Anything requiring a database or a request. |
| **fakebench behaviour** | Observable application logic against a modelled bench. | SQL correctness, InnoDB isolation, indexes, concurrency, migrations. |
| **Mutation** | That the above suites actually fail when the behaviour breaks. | Anything no mutation targets. |
| **Real runtime** | MariaDB, Redis, workers, queues, `bench migrate`, browser Desk. | — **not available in this environment; nothing below is claimed.** |
